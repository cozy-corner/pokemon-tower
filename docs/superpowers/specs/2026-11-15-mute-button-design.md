# ミュートボタン

## 目的

BGM を画面から消せるようにする。音の大きさは端末の音量で変えてもらい、ゲーム側はミュートの切り替えだけを持つ。

## やること

- 画面の右上、HUD の下(名前ラベルと同じ高さの右端)にスピーカーのアイコンボタンを置く。
- 押すたびに BGM の音あり / なしが切り替わり、アイコンも 🔊 / 🔇 相当の SVG に変わる。
- ミュートの状態は localStorage に保存し、次に開いたときも引き継ぐ。

## やらないこと

- 音量スライダー(iOS Safari では `audio.volume` が効かないことがあり、スマホで触りにくい)。
- 設定画面。
- キーボードショートカット(頼まれていない。必要なら別途)。

## 作り方の候補

- **HTML のボタン(採用)**: 回転・落下ボタンと同じく `index.html` の `#stage` に置く。既存のボタンがすべて HTML なので揃える。
- canvas に描いてクリック判定する: 既存の作りと揃わず、判定やアクセシビリティを自前で持つことになる。

## 決めたこと

- 切り替えは `audio.muted` で行う(iOS でも効く)。
- `startBgmOnFirstGesture` がミュートを切り替える手段を返すようにする。
- ボタンを押すこと自体も最初のジェスチャーになるが、ミュート中に再生が始まっても無音なので問題ない。

## 実装者に任せること

- アイコンの SVG の形、ボタンの大きさと色(既存の HUD・ボタンの見た目に合わせる)。
- localStorage のキー名(既存の `pokemon-tower.best` に倣う)。
